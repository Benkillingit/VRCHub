# Contribute to VRCHub

**Volunteer coders wanted — free will, zero pressure.** VRCHub is a free, MIT-licensed VRChat companion: one Python file, stdlib-only core (everything works without pip installs; face tracking is optional deps).

## What's already built
- OSC chatbox, AI relay, scheduled messages, countdowns
- VRChat API login (email or username + TOTP 2FA), online friends, avatar search/management
- Unlimited avatar vault with cloud sync (private GitHub repo database)
- Webcam face tracking (optional opencv + mediapipe)
- Desktop overlay, full official VRChat OSC input coverage

## Open spots
- **Windows tester** — run it, report bugs (the dev builds blind; no Windows box yet)
- **macOS/Linux tester** — overlay & path handling untested outside Windows
- **Packaging** — PyInstaller/exe build so non-Python users can run it
- **Ideas for v5** — feature sweep of VRCX/VRCOSC/MagicChatbox is done; what's next?

## How to help
Open an issue, comment, or just send a PR. No commit quotas, no obligations — free-will contributions only.
